## 📞 **Build Support**

### **If Build Fails:**
1. Check EAS dashboard for error logs
2. Run: `eas build --platform android --profile preview`
3. Clear cache: `eas build --platform android --profile production-fixed --clear-cache`

### **Common Solutions:**
- **Timeout:** Retry during off-peak hours
- **Memory Issues:** Use preview profile instead
- **Dependency Errors:** Check package.json versions
